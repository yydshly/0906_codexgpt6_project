# 体验、视觉与实现规格

## 参考材料的使用边界

reference/reference.png 是用户提供的单帧截图。可参考浅色桌面、左侧画布、右侧木质调色板、紧凑工具栏和克制的拟物风格。

这张截图不能证明原产品使用了什么技术，也不能证明其混色、干燥或笔刷物理行为。
不要把截图中的视频进度条、播放按钮或外部页面控件画进产品；不要把截图整体设为页面背景来伪造实现。
应用需要自行实现界面与绘画行为；第三方纹理、素材、代码引入前要记录来源并核对使用条件。

## 页面视觉

桌面主界面以画布为主体。浅暖灰或米白背景，细腻且不过强的材质变化；画布有织纹、轻微厚度和接触阴影；右侧木质色板上的颜色可呈少量颜料堆积感。

工具栏紧凑，保留撤销、画笔参数、完成与必要设置。调色板、画笔与辅助工具都服务于绘画，不做大量仪表盘卡片、霓虹渐变或装饰性控制项。

有可见按钮就必须有可用行为；未做的功能不显示可点击假入口。

首个目标是 Windows 桌面浏览器。需要响应式布局与统一指针输入设计，但不在未经真机测试时宣称 iPad、Apple Pencil 或所有手机完整适配。

## 一个关键交互的完整定义：落笔

输入：选中的颜色、笔刷大小、上色量，以及指针轨迹；硬件有压感时读取压感。

动作：用户按下并移动指针，松开结束一笔。

反馈：笔触连续跟随轨迹；方向和边缘有刷毛特征，不是规则圆头线条；颜料覆盖与局部基础混色有一致规则。

结果：生成可撤销的真实绘画操作，更新颜色与材质状态；成品导出包含这笔真实绘制的结果。

异常：指针移出、窗口失焦、pointercancel、缩放与布局变化后不得出现卡住的按下状态或大幅坐标偏移。

鼠标没有真实压感，不得伪称获得了压感。可提供固定压力，并选用速度变化作为可解释的辅助效果；它与真实硬件压力必须区分。

## 推荐实现路线：单一主路线，按风险验证

这是方案建议，不是对原演示实现的判断。

UI 层优先沿用既有项目框架；空仓库可使用 React + TypeScript + Vite。不要为本项目无必要更换原有框架。

绘画输入与笔触数据独立于 UI 组件。使用统一指针事件、路径插值与适当平滑；支持时利用合并的指针采样点，不支持时正常回退。绘画热路径不要依赖每个采样都触发 UI 框架状态更新。

画布与材质以二维绘画状态加局部厚度/法线光照为优先验证方向。WebGL 可承担材质显示与必要的绘画处理；Canvas 2D 可承担辅助、原型或降级。不要因为需要厚涂观感就先建完整 3D 房间，也不默认引入完整流体求解器。

色层存储笔触颜色与覆盖；高度或等价材质数据描述堆积变化；统一光照根据局部形状给出柔和亮暗。必须证明效果来自实际笔触数据，而非整张画布一层固定阴影滤镜。

如果初步实现发现这条路线不足以满足效果、性能或可维护性要求，应展示实际实验结果与替代方案，等待批准，而不是静默扩展技术栈。

## 混色边界

首版要求“可预测的基础颜料感混色”，不声称完整光谱准确或真实颜料化学模拟。

重叠区域应体现可解释的覆盖与局部混合关系，不允许把整个画布每帧模糊来冒充混色。

以固定颜色和轨迹建立测试样本，检查混色是否发生在接触区域，边缘是否保持合理方向，反复涂抹是否可控。

可以借鉴公开实现，但应核查兼容性、维护成本与使用条件。不要未经确认引入收费或用途受限的混色引擎。

## 引导与绘画分离

M2 仅实现“旅行日落”一个主题。可采用简单数据结构表达主题标题、色板、参考素材和步骤。

步骤例如：天空大色块 → 远山与水面 → 反光与个人细节。这是体验引导，不应宣称已具备专业教学验证。

参考图和辅助轮廓是可关闭的引导层，不属于用户画作。用户可以跳过步骤与关闭提示；必须保留自由落笔与个人选择。

导出不得把参考图或引导轮廓混入画作。

第二个主题真的需要时再抽象更多配置，不提前建设插件化绘画平台。

## 作品数据与容错

逻辑画布坐标与屏幕显示坐标分离。窗口尺寸改变不应改变既有笔触位置或清空作品。

撤销需要恢复颜色与材质的完整状态，而不只是删一条 UI 列表记录。至少支持最近 20 笔；内存应有边界。

M2 的本地持久化应保存继续编辑所需的数据，而不仅是预览 PNG。可选择笔触记录与有限检查点等方式；必须记录格式版本和画笔必要参数。

使用随机刷毛或噪声时应考虑可重放的一致性，例如固定种子和版本。不同 GPU/浏览器像素级一致性不能未经测试承诺。

保存状态清楚区分保存中、已保存和保存失败。只对已完成且显示保存成功的操作承诺刷新恢复；不隐瞒存储失败。

本地保存不等于永久云备份，应提示浏览器数据清理可能导致丢失，鼓励导出。若后续接个人照片，默认本地处理；上传处理必须明确告知与授权。

## 渲染降级

前置限制工作画布分辨率、设备像素比和中间纹理数量，报告实际测试值。

低性能设备可降低材质分辨率、光照细节与非必要动画。不可为了性能关闭所有核心笔触特征后仍宣称油画效果通过。

WebGL 不可用或上下文丢失时，要提供明确状态和恢复/降级路径，避免整页白屏；尽可能保留已经成功保存的作品和基础编辑能力。
